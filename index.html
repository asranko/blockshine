    Questions, answered

    Which files can I use?

    Start with a CSV export from an ad platform, analytics dashboard or spreadsheet. The first row should contain column names. XLSX is not supported in this beta; export it to CSV first.

    Does this connect directly to Google or Meta?

    No. This version works with files you export yourself. Direct API connections would require account permissions, secure token handling and additional testing.

    Does the tool upload my data?

    No. The current report generator reads the file locally in your browser. Do not use a shared or public computer for confidential client data.

    Are recommendations guaranteed to be correct?

    No. The tool uses transparent rules and common metric names. It may misread unfamiliar columns or metric definitions, so review the report before sharing it.

    BrieflyReport is an independent beta tool and is not affiliated with Google, Meta or any analytics provider. It does not guarantee performance outcomes.
